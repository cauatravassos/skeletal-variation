# 🦴 Skeletal Variation — Data Analysis with Python

## 📌 About the Project

This project explores skeletal variation across different species using Python and data analysis techniques.

Developed as a guided educational project during the **Cisco Networking Academy – Data Science Foundations with Python** course.

The goal is to investigate skeletal data, organize information, identify patterns, and create visualizations using Python.

## 🎯 Project Objectives

- Load and explore CSV datasets using Pandas.
- Analyze skeletal information from different species.
- Count and organize data using Python.
- Create visualizations with Matplotlib.
- Practice exploratory data analysis (EDA).

## 🛠️ Technologies Used

- **Python** — Programming language.
- **Pandas** — Data manipulation and analysis.
- **NumPy** — Numerical computing.
- **Matplotlib** — Data visualization.
- **Jupyter Notebook** — Interactive development environment.

## 📊 Analysis

The project includes exploratory analysis of skeletal datasets, including:

- Adult human skeletal structure.
- Bird neck vertebrae.
- Mammal neck vertebrae.

Data is processed using Pandas, while Matplotlib is used to generate graphical visualizations.

## 💻 How to Run

1. Clone this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

3. Open the Jupyter Notebook.
4. Run the cells to explore the datasets and visualizations.
